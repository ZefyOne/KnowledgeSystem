# 9.4 软件应用 · Software & Apps

### Using Software

I use many **apps** on my phone. I **install** a new **application** to learn English. First, I **open** the **app** and read the **settings**. Then I **update** it to the latest **version**.

The **interface** is simple. I see **icons** and a **menu** with several **buttons**. I **save** my work to a **file** in a **folder**. If I make a mistake, I **delete** it or **copy** and **paste** again. If there is an **error**, the app shows a message.

**整体大意**

我手机上有很多应用。我安装了一个新的学英语的应用。首先打开应用、查看设置，然后把它更新到最新版本。

界面很简单。我看到图标和带有几个按钮的菜单。我把工作保存到文件夹里的文件中。如果出错，我就删除，或者重新复制粘贴。如果出现错误，应用会显示提示信息。
