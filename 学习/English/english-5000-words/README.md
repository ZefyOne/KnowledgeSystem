## 使用方法

1. **先通读故事**，借助「整体大意」理解意思，不必逐词翻译。
2. **再背生词**，重点记文中加粗的核心词，配合「生词解释」表。
3. **最后复述**，合上故事，用英文把大意讲一遍，能说出来才算掌握。
4. 同一个词在不同主题出现时，注意它在不同语境下的含义和搭配。
