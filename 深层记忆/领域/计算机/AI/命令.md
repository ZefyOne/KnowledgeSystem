## Claude Code 常用斜杠命令

### 基础命令

| 命令        | 功能                     |     |
| --------- | ---------------------- | --- |
| `/help`   | 显示帮助信息，列出所有可用命令        |     |
| `/clear`  | 清除当前对话历史，重置上下文         |     |
| `/reset`  | 重置会话，相当于重新启动           |     |
| `/status` | 查看当前会话状态、已用 token 等信息  |     |
| `/cost`   | 查看当前会话的 token 使用量和费用估算 |     |

### 搜索与导航

| 命令                | 功能                     |
| ----------------- | ---------------------- |
| `/search <query>` | 在项目中搜索文件内容（基于 ripgrep） |
| `/glob <pattern>` | 按 glob 模式匹配文件名，快速定位文件  |
| `/find`           | 交互式文件查找                |
| `/OpenAI-adapter` | 查看文件的完整内容（相当于 cat）     |

### 版本控制

| 命令        | 功能                 |
| --------- | ------------------ |
| `/git`    | 查看 git 状态和最近的变更    |
| `/commit` | 交互式创建 git commit   |
| `/pr`     | 创建或查看 Pull Request |
| `/diff`   | 查看当前未暂存的变更差异       |

### 项目与配置

| 命令 | 功能 |
|------|------|
| `/init` | 初始化 CLAUDE.md 文件（项目文档） |
| `/config` | 查看或修改 Claude Code 配置（settings.json） |
| `/memory` | 查看或更新长期记忆 / 项目上下文 |
| `/docs` | 查看项目文档 |
| `/plan` | 进入计划模式 |
| `/review` | 启动代码审查 |
| `/security-review` | 启动安全审查 |

### 代码操作

| 命令 | 功能 |
|------|------|
| `/build` | 执行构建命令 |
| `/test` | 运行测试 |
| `/fix` | 尝试自动修复错误或警告 |
| `/lint` | 运行代码检查并修复 |
| `/format` | 格式化代码 |
| `/refactor` | 对选中代码进行重构 |

### 会话控制

| 命令 | 功能 |
|------|------|
| `/compact` | 压缩对话历史以释放上下文窗口 |
| `/copy` | 复制最后一次回复到剪贴板 |
| `/feedback` | 对本次回复提供反馈 |
| `/undo` | 撤销上一次文件修改 |

### 其他实用命令

| 命令 | 功能 |
|------|------|
| `/explain` | 解释选中的代码或文本 |
| `/simplify` | 简化或优化代码 |
| `/read` | 读取文件内容 |
| `/edit` | 编辑文件（需要指定文件路径和修改内容） |
| `/web` | 启用联网搜索 |
| `/loop <间隔> <命令>` | 定时重复执行某个命令（如 `/loop 5m /status`） |

> 💡 **提示**：在对话中输入 `/` 即可弹出命令自动补全列表。部分命令（如 `/search`、`/glob`）需要在项目目录下使用才有效。`/loop` 是类似于 cron 的定时任务功能，最小间隔 60 秒，最长 7 天自动过期。
